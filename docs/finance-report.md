# 班费后端实现与验证

## 接口行为

- `registerFinance(app, db)` 注册班费总览、独立台账、缴费事项、个人缴费、修订记录、名册和 XLSX 导出接口。
- 台账金额以整数分处理。只允许一条生效期初记录，修订和作废保留原记录的快照、版本、操作者、原因与时间。
- 缴费事项可以登记多笔部分实缴。超缴按实际到账入账。个人缴费和关联收入在同一个 SQLite 事务中新增、修订或作废。
- 新增台账与缴费使用各自的幂等键。相同账号原样重试会收到原有登记结果。复用幂等键提交不同数据会收到 409。修订和作废采用乐观锁，同一操作者用原版本重试同一请求可读取原修订结果。
- 管理员可以查看完整记录和导出。只有具有财务维护标记的班委可以记账。普通班委和学生能查看有效收支、自己的缴费及面向自己的缴费事项。关联收入在公示账目统一显示“班费收入”，隐藏对应缴费记录 ID 和登记人。
- 凭证通过文件模块确认后绑定。个人缴费新增和修订支持可选的 `publicReceipt` 字段，默认私密。公开凭证从当前有效记录读取，移除或作废后会收回普通成员的下载授权。
- 修订接口返回操作类型 `action`（`update` 或 `void`）和操作前快照 `data`。Excel 文件通过共享存储模块发布，包含余额总览、收支台账、缴费事项和个人缴费登记四个工作表。

## 验证

- `node_modules/.bin/tsx.cmd --test tests/finance.test.ts` 覆盖重复登记、部分与超额缴费、修订和作废同步、溢出回滚、角色与凭证授权、XLSX 重新读取。
- 财务模块及测试通过针对性 TypeScript 检查。
- Excel 和凭证签发使用测试存储适配器验证。腾讯云 COS 联调需要实际配置。
