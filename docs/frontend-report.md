# 前端交付记录

React 与 TypeScript 前端使用同源 API 和服务端会话。游客可查看简介、公开课表及登录入口，受限页面在登录成功后可返回。首次登录和重置后的账号需要更新密码。页面按已登录身份显示操作入口，写入权限仍由 API 校验。

| 模块 | 界面覆盖 |
| --- | --- |
| 班级首页 | 今日实际课程、按截止时间排序的待办、最新作业和快捷入口。管理员可看近期办理进度 |
| 作业公告 | 草稿、发布、撤回、归档、附件、提交与个人历史、名单进度、Excel 及提交附件打包 |
| 课程表 | 每周节次网格、手机当日卡片、日期导航、周模板生效日、节次编辑、停课和临时调课 |
| 事务办理 | 报名、登记、材料收集，自定义文本、选项及附件字段，参与名单、结果和历史 |
| 资料中心 | 关键字、类别及更新日期筛选，置顶、归档、外链、附件、编辑和历史版本 |
| 班费管理 | 余额、期初金额、收支、缴费事项与实缴、部分及超缴、凭证、筛选、修订、作废和导出。写操作限指定班委 |
| 班级信息 | 公开简介及照片、学期与休课日设置、成员展示资料、班委分工和值日安排 |
| 账号设置 | 管理员创建、批量创建、改身份、启停、重置密码及授予班费维护权限 |

附件上传由后端发放签名地址，浏览器上传后请求后端确认。下载、预览与导出走鉴权签名，未配置 COS 时上传入口显示原因。提交附件可打包下载全部最新记录或选定成员的最新记录。

已运行 `npm run build`，包括 TypeScript 类型检查和 Vite 构建。显式将构建进程的 `NODE_ENV` 设为 `production` 时，构建无大小警告，入口脚本约 305 kB，gzip 约 97 kB。任务、资料及班级管理、班费模块分别按路由加载。真实 COS 桶需在部署环境另行联调。
