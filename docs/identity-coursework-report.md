# 账号、作业与事务后端交付

## 实现范围

- 提供登录、退出、首次登录强制改密和管理员账号维护接口。密码使用带随机盐的 scrypt 哈希，服务端只保存会话令牌的 SHA-256 哈希。会话绝对有效期为七天。改密、密码重置和停用撤销旧会话，身份与财务授权在每次请求中读取。
- 生产环境为会话 Cookie 启用 Secure，写请求校验 Origin，登录失败按来源 IP 和账号限速。名单创建整体写入，停用或降级最后一个有效管理员会返回冲突。
- 作业与事务采用同一套草稿、发布、归档、参与名单和版本校验流程。首次发布保留名单快照，撤回后学生只可访问本人提交历史。账号停用或转管理员时，未完成的参与记录改为免交。
- 提交按服务器时间记录迟交标志及历史版本。事务表单在收到首份提交后冻结原有字段，允许追加选填字段。完整参与名单、全班提交明细和 XLSX 导出限管理员及班委使用，导出保留免交记录和提交时的字段名称。归档任务通过重新发布开放，开放前校验截止时间。
- 管理员和班委可将全班或指定学生的最新提交附件打包为 ZIP。提交详情和历史包含提交时的表单定义，便于页面展示历史答案。

## 验证

- `npm test` 通过 26 项测试，其中账号、作业与事务 11 项。覆盖初始密码、会话撤销、来源校验、限速、批量回滚、最后管理员保护、名单快照、撤回后的历史访问、停用免交、迟交、表单冻结、附件可见性、XLSX 内容、ZIP 选择与版本筛选及缺少 COS 的错误状态。
- 导出与附件流程通过内存存储适配器验证。真实 COS 服务的签名、权限策略与跨域行为需要部署配置后验证。
- 本次 TypeScript 检查报告了前端整合中的错误。账号、作业与事务后端及对应测试未报告类型错误。
